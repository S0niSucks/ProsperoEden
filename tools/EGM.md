# Encore host-tool contracts

## Overview

Encore-authored dependency preparation, builds, packaging, installation, local telemetry analysis and glyph research/asset tooling. This index complements the existing [README](./README.md); dedicated regression fixtures and third-party implementations are not production interfaces. `[deps.py:main]` `[build-package.sh:release-stage]` `[analyze-ps5-logs.py:main]`

## Invariants

- **Export privacy is name/path based:** [network_privacy.py](./network_privacy.py) rejects any normalized `config/network-shares.json*` or `config/nextendo` path, case-insensitively across both separators and trailing-dot/space aliases. Metadata/ancestor checks reject symlinks, reparse points, special nodes and unsafe path spellings. Private children are rejected before their metadata/content is inspected. `[network_privacy.py:private_network_path]` `[network_privacy.py:export_path_metadata]` `[network_privacy.py:preflight_export_tree]`
- Distribution preflights staged input before deleting output or invoking image tooling, including image-only mode. Inputs must stay quiescent through packaging: this narrow policy is neither a content-secret scan nor concurrent-mutation protection. `[ci/make-dist.py:preflight_export_tree]` `[network_privacy.py:preflight_export_tree]`
- Pin/receipt/hash guarantees are operation-specific. Non-Git dependency verification does not rehash every installed byte; offline mode does not prove child subprocess network isolation. Per-file atomic staging is not a whole-install transaction. `[deps.py:verify]` `[deps.py:pinned_hash]` `[install-vendored-radv.py:install]` `[install-ftp.py:main]`
- Source oracles and static CI membership do not prove current compiled behavior. The active-source boundary checker rejects invoking the historical Vulkan generator from the active CMake boundary. Packaged metadata explicitly records `hardware_qualified=false`. `[check-active-cmake-source-boundary.py:active_mutation]` `[check-eden-audit-verification-matrix.py:build_matrix]` `[package-headless-native.sh:hardware_qualified]`
- Presentation/log observations do not establish guest simulation FPS, scanout, root cause or deadlock. Research URLs, names and pixel/byte geometry do not establish title/version/button semantics or native compatibility; candidate drafts require explicit review. `[analyze-r01-frame-metrics.py:summary]` `[analyze-ps5-network-audit.py:summarize]` `[ps-glyph-mod-discovery.py:discover]` `[ps-glyph-reconstruct.py:verified_cross_platform]` `[ps-glyph-scan.py:draft_spec]`
- Closure command success is not readiness unless the caller requests `--require-ready`; even ready status is only readiness for human review, never automatic release approval or authenticated hardware evidence. `[check-ps5-closure.py:main]` `[check-ps5-closure.py:audit]`

## Side Effects

- Dependency/build/materialization tools can fetch, extract, compile, link, modify caches and stage outputs. Packaging can delete the previous stage; full distribution assembly recreates `dist`. FTP installation mutates the remote app file-by-file and is not transactional. `[deps.py:main]` `[prepare-build.sh:step]` `[build-package.sh:EDEN_PACKAGE_DIR]` `[ci/make-dist.py:dist]` `[install-ftp.py:main]`
- Glyph research with explicit network enablement/provider tools makes bounded external requests; texture/pack/catalog tools write selected outputs. Output-path aliasing is not universally prevented, so do not assume every command preserves inputs. No automatic game compatibility/activation follows from these writes. `[ps-glyph-mod-discovery.py:request_bytes]` `[ps-glyph-curl-search.py:search]` `[ps-glyph-botw-stage-pack.py:stage]` `[ps-glyph-pack.py:install]`
- Environment setup can create host wrappers/symlinks, and syntax/audit tools may invoke compilers or Git. Their names do not imply a uniformly read-only invocation. `[host-env.sh:eden_host_env]` `[check-toolchain.sh:need]` `[check-native-source-syntax.py:main]` `[check-eden-optimization-coverage.py:tracked]`
